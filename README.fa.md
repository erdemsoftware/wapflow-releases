## WapFlow Windows چیست؟

**WapFlow Windows** یک برنامه دسکتاپ است که حساب‌های واتساپ شما را روی کامپیوتر خودتان اجرا می‌کند:
ارسال کمپین، پاسخ خودکار با هوش مصنوعی، صندوق ورودی، ابزارهای گروه و کانال، و ساخت فهرست مخاطبین از Google Maps.

لایسنس‌ها در **[wapflow.net](https://wapflow.net)** خریداری می‌شوند و از همان حساب مدیریت می‌شوند.

> این مخزن فقط **نصاب‌های کامپایل‌شده** را میزبانی می‌کند. کد منبع **شامل نمی‌شود**.

## نیازمندی‌های سیستم

- Windows 10 / 11 (64 بیتی)
- حداقل 2 گیگابایت رم (با افزایش تعداد حساب‌های همزمان در حال اجرا، رم بیشتر توصیه می‌شود)
- اتصال به اینترنت

## نصب

1. نصاب را دانلود و اجرا کنید.
2. اگر Windows هشدار «ناشر ناشناس» نشان داد، روی **اطلاعات بیشتر ← در هر صورت اجرا کن** کلیک کنید.
3. وقتی برنامه باز شد، کلید لایسنس خود را وارد کنید. آن را در [wapflow.net](https://wapflow.net) ← **My Windows license** پیدا می‌کنید. → **لایسنس ویندوز من**
