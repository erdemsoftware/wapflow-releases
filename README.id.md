## Apa itu WapFlow Windows?

**WapFlow Windows** adalah aplikasi desktop yang menjalankan akun WhatsApp Anda di komputer Anda sendiri:
pengiriman kampanye, balasan otomatis bertenaga AI, kotak masuk, alat grup dan saluran, serta pembuatan daftar kontak dari Google Maps.

Lisensi dibeli di **[wapflow.net](https://wapflow.net)** dan dikelola dari akun yang sama.

> Repositori ini hanya menyediakan **installer hasil kompilasi**. Kode sumber **tidak** disertakan.

## Persyaratan sistem

- Windows 10 / 11 (64-bit)
- RAM minimal 2 GB (disarankan lebih banyak seiring bertambahnya jumlah akun yang berjalan bersamaan)
- Koneksi internet

## Instalasi

1. Unduh dan jalankan installer.
2. Jika Windows menampilkan peringatan "unknown publisher", klik **Info lebih lanjut → Tetap jalankan**.
3. Saat aplikasi terbuka, masukkan kunci lisensi Anda. Anda dapat menemukannya di [wapflow.net](https://wapflow.net) → **Lisensi Windows saya**.
