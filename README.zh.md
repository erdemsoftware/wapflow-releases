## 什么是 WapFlow Windows？

**WapFlow Windows** 是一款桌面应用，在您自己的电脑上运行您的 WhatsApp 账号：
批量营销发送、AI 自动回复、收件箱、群组与频道工具，以及从 Google Maps 生成联系人列表。

授权在 **[wapflow.net](https://wapflow.net)** 购买，并在同一账号中管理。

> 本仓库仅提供**已编译的安装程序**，**不包含**源代码。

## 系统要求

- Windows 10 / 11（64 位）
- 至少 2 GB 内存（同时运行的账号越多，建议内存越大）
- 互联网连接

## 安装

1. 下载并运行安装程序。
2. 如果 Windows 显示“未知发布者”警告，请点击 **更多信息 → 仍要运行**。
3. 应用打开后，输入您的授权密钥。您可以在 [wapflow.net](https://wapflow.net) → **我的 Windows 授权** 中找到它。
