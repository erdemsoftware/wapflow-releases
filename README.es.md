## ¿Qué es WapFlow Windows?

**WapFlow Windows** es una aplicación de escritorio que ejecuta tus cuentas de WhatsApp en tu propio ordenador:
envío de campañas, respuesta automática con IA, bandeja de entrada, herramientas para grupos y canales, y creación de listas de contactos desde Google Maps.

Las licencias se compran en **[wapflow.net](https://wapflow.net)** y se gestionan desde la misma cuenta.

> Este repositorio solo aloja los **instaladores compilados**. El código fuente **no** está incluido.

## Requisitos del sistema

- Windows 10 / 11 (64 bits)
- Al menos 2 GB de RAM (se recomienda más a medida que aumenta el número de cuentas que se ejecutan simultáneamente)
- Conexión a internet

## Instalación

1. Descarga y ejecuta el instalador.
2. Si Windows muestra una advertencia de "editor desconocido", haz clic en **Más información → Ejecutar de todas formas**.
3. Cuando se abra la aplicación, introduce tu clave de licencia. La puedes encontrar en [wapflow.net](https://wapflow.net) → **Mi licencia de Windows**.
