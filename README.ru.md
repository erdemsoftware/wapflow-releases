## Что такое WapFlow Windows?

**WapFlow Windows** — настольное приложение, которое запускает ваши аккаунты WhatsApp на вашем компьютере:
рассылка кампаний, автоответчик на основе ИИ, входящие, инструменты для групп и каналов, а также создание списков контактов из Google Maps.

Лицензии приобретаются на **[wapflow.net](https://wapflow.net)** и управляются из того же аккаунта.

> Этот репозиторий содержит только **скомпилированные установщики**. Исходный код **не** включён.

## Системные требования

- Windows 10 / 11 (64-бит)
- Не менее 2 ГБ оперативной памяти (чем больше одновременно работающих аккаунтов, тем больше памяти рекомендуется)
- Подключение к интернету

## Установка

1. Скачайте и запустите установщик.
2. Если Windows покажет предупреждение «неизвестный издатель», нажмите **Подробнее → Все равно запустить**.
3. Когда приложение откроется, введите ключ лицензии. Его можно найти на [wapflow.net](https://wapflow.net) → **Моя лицензия Windows**.
