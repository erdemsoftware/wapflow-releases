## Qu'est-ce que WapFlow Windows ?

**WapFlow Windows** est une application de bureau qui fait fonctionner vos comptes WhatsApp sur votre propre ordinateur :
envoi de campagnes, réponse automatique alimentée par l'IA, boîte de réception, outils pour les groupes et les canaux, et création de listes de contacts à partir de Google Maps.

Les licences sont achetées sur **[wapflow.net](https://wapflow.net)** et gérées depuis le même compte.

> Ce dépôt ne contient que les **installateurs compilés**. Le code source **n'est pas** inclus.

## Configuration requise

- Windows 10 / 11 (64 bits)
- Au moins 2 Go de RAM (davantage est recommandé à mesure que le nombre de comptes exécutés simultanément augmente)
- Connexion Internet

## Installation

1. Téléchargez et lancez l'installateur.
2. Si Windows affiche un avertissement « éditeur inconnu », cliquez sur **Informations complémentaires → Exécuter quand même**.
3. Lorsque l'application s'ouvre, saisissez votre clé de licence. Vous la trouverez sur [wapflow.net](https://wapflow.net) → **Ma licence Windows**.
