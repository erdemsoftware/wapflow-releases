## Was ist WapFlow Windows?

**WapFlow Windows** ist eine Desktop-Anwendung, die Ihre WhatsApp-Konten auf Ihrem eigenen Computer betreibt:
Kampagnenversand, KI-gestützte automatische Antworten, Posteingang, Werkzeuge für Gruppen und Kanäle sowie das Erstellen von Kontaktlisten aus Google Maps.

Lizenzen werden auf **[wapflow.net](https://wapflow.net)** gekauft und über dasselbe Konto verwaltet.

> Dieses Repository enthält nur die **kompilierten Installer**. Der Quellcode ist **nicht** enthalten.

## Systemanforderungen

- Windows 10 / 11 (64-Bit)
- Mindestens 2 GB RAM (mehr wird empfohlen, je mehr Konten gleichzeitig laufen)
- Internetverbindung

## Installation

1. Laden Sie den Installer herunter und starten Sie ihn.
2. Wenn Windows eine Warnung zu einem „unbekannten Herausgeber“ anzeigt, klicken Sie auf **Weitere Informationen → Trotzdem ausführen**.
3. Wenn sich die App öffnet, geben Sie Ihren Lizenzschlüssel ein. Sie finden ihn auf [wapflow.net](https://wapflow.net) → **Meine Windows-Lizenz**.
