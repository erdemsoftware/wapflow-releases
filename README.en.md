## What is WapFlow Windows?

**WapFlow Windows** is a desktop application that runs your WhatsApp accounts on your own computer:
campaign sending, AI-powered auto-reply, inbox, group and channel tools, and building contact lists from Google Maps.

Licenses are purchased at **[wapflow.net](https://wapflow.net)** and managed from the same account.

> This repository only hosts the **compiled installers**. The source code is **not** included.

## System requirements

- Windows 10 / 11 (64-bit)
- At least 2 GB RAM (more is recommended as the number of simultaneously running accounts grows)
- Internet connection

## Installation

1. Download and run the installer.
2. If Windows shows an "unknown publisher" warning, click **More info → Run anyway**.
3. When the app opens, enter your license key. You can find it at [wapflow.net](https://wapflow.net) → **My Windows license**.
