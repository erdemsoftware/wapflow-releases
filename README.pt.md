## O que é o WapFlow Windows?

**WapFlow Windows** é um aplicativo de desktop que executa suas contas do WhatsApp no seu próprio computador:
envio de campanhas, resposta automática com IA, caixa de entrada, ferramentas para grupos e canais, e criação de listas de contatos a partir do Google Maps.

As licenças são compradas em **[wapflow.net](https://wapflow.net)** e gerenciadas na mesma conta.

> Este repositório hospeda apenas os **instaladores compilados**. O código-fonte **não** está incluído.

## Requisitos do sistema

- Windows 10 / 11 (64 bits)
- Pelo menos 2 GB de RAM (recomenda-se mais conforme aumenta o número de contas executadas ao mesmo tempo)
- Conexão com a internet

## Instalação

1. Baixe e execute o instalador.
2. Se o Windows mostrar um aviso de "editor desconhecido", clique em **Mais informações → Executar assim mesmo**.
3. Quando o aplicativo abrir, digite sua chave de licença. Você pode encontrá-la em [wapflow.net](https://wapflow.net) → **Minha licença do Windows**.
